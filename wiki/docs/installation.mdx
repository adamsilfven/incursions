# Installation

Incursions requires Minecraft Java Edition 1.21.1, Java 21, and NeoForge 21.1.259 or newer within the 21.1.x series.

## Where to install it

For a dedicated server, put the release JAR in the server's `mods` folder. For single-player or LAN hosting, put it in the host's client `mods` folder. Remove the previous Incursions JAR when updating so only one version is installed.

The encounters run on the server. Players can join without installing Incursions on their clients. Installing it on the client also provides the Incursions settings button in the pause menu.

The Aether, The Undergarden, and Twilight Forest are optional. Their profiles become available when the corresponding mods are installed on the server. Players still need any dimension mods required by the server; Incursions' optional client installation does not remove those mods' requirements.

## Updating

Replacing the JAR preserves saved configuration. If you changed settings for testing, restore the [approved defaults]($configuration) separately. Existing datapacks can override the built-in encounter definitions, so check those too if the new version behaves like an older one.
