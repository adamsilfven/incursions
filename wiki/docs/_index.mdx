# Incursions

Portals let you into other worlds. Incursions gives those worlds a chance to return the favor.

Incursions adds hostile encounters around active portals and lodestone anchors. Fight through the attackers, deal with the occasional enhanced enemy, and collect a reward when the encounter is finished. Only one incursion runs at a time, and every portal type shares the same cooldown.

This wiki documents Incursions 1.0.1 for Minecraft 1.21.1, NeoForge 21.1.x, and Java 21. The Nether works on its own. The Aether, The Undergarden, and Twilight Forest add their own encounters when those mods are installed.

Start with [installation]($installation), then read [portals and anchors]($portals) and [encounters]($encounters). Server owners can find the defaults under [configuration]($configuration).
