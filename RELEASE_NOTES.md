# Incursions 1.0.1

Release for Minecraft 1.21.1, NeoForge 21.1.259+ within 21.1.x, and Java 21.

Includes Nether encounters and optional Aether, Undergarden, and Twilight Forest integrations, shared cooldowns, wave encounters, enhanced enemies, victory rewards, and the pause-menu settings control.

Default trigger checks run every 100 ticks (5 seconds), with a shared 21600-tick (18-minute) cooldown. Saved settings survive JAR updates. Use the default config/reset helper if you previously changed these values for testing.

Install the release JAR once and remove the previous Incursions JAR. Existing custom datapacks continue to override built-in definitions.
